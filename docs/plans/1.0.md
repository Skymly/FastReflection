# FastReflection 1.0 plan

The authoritative definition of the 1.0 release candidate, named by map [#1](https://github.com/Skymly/FastReflection/issues/1). The scope was decided by the wayfinder council on tickets #5–#19; this document aggregates their verdicts (spec hop [#22](https://github.com/Skymly/FastReflection/issues/22)). The pruning rules and considered options live in [ADR-0005](../adr/0005-the-1-0-surface-is-the-pruned-reference-union.md); the per-member spellings live in [`docs/specs/1.0-public-api.md`](../specs/1.0-public-api.md) (referred to below as **S**); the build and CI gates live in [`docs/specs/1.0-quality-gates.md`](../specs/1.0-quality-gates.md) (**G**).

## Destination

A 1.0 release candidate of `Skymly.FastReflection` that the maintainer can accept and then release themselves. It covers everyday .NET reflection at production quality; the scope is the union of the capabilities of fast-member, Dynamitey, Namotion.Reflection and DotNext, pruned by council.

- This file is the authoritative definition: the scope matrix below marks every candidate In / Satellite / post-1.0 / wontfix, maps In items to public API, tests and README sections, and links the rest to council minutes or ADRs, followed by the quality gates and the acceptance checklist.
- Every In item is implemented, tested, documented and merged to `main`; every quality gate is met with evidence.
- All open issues are handled; the final audit has no unresolved 1.0 blocker.
- `docs/release/1.0-acceptance.md` is ready for the maintainer's acceptance.
- This effort creates no tag, GitHub Release or NuGet push; the maintainer releases 1.0 after accepting.

Hard constraints (map Notes): `<Version>` stays `0.1.0` and the changelog says `## [1.0.0] - Unreleased`; one PR per ticket; the 0.1 baseline is commit `7fcfffa`.

## Scope matrix

Every candidate item from the council trace tables and the shipped 0.1 surface appears exactly once. Verdict strings are transcribed verbatim from the deciding tickets. Status is `decided` until the implementing PR merges, then `shipped`; a row that says `In` today is a scope claim, not a capability claim.

For **In** rows, *Lands at* names the spec section that spells the surface, the test suite that covers it, and the README anchor that documents it (anchors marked `#20` are added by that spec's README slice). For **Satellite / post-1.0 / wontfix** rows, *Lands at* links the council minute or ADR that decided it. Items a ticket routed onward (`→ #N input`) keep their origin row for traceability but carry their final verdict only in the receiving ticket's section — they count once.

## Quality gates

Spelled in [`docs/specs/1.0-quality-gates.md`](../specs/1.0-quality-gates.md) ([#21](https://github.com/Skymly/FastReflection/issues/21)); listed here so this file stands alone as the 1.0 definition.

- **Analyzer and warning gates** — `IsAotCompatible=true` on every shipped project (IL2xxx/IL3xxx become errors under warnings-as-errors); `AnalysisLevel=latest`; `TreatWarningsAsErrors=true` on shipped projects only; `Microsoft.CodeAnalysis.PublicApiAnalyzers` with `PublicAPI.Shipped.txt`/`Unshipped.txt` per package (`#if`-conditional entries for net8+-only surface); `Microsoft.DotNet.PackageValidation` intra-package checks only, `#if`-gated differences recorded in suppressions with reasons.
- **NoWarn inventory** — the shipped `1591` suppression is removed (XML documentation required on public members, `<exception>` included per [#8](https://github.com/Skymly/FastReflection/issues/8)); `NETSDK1138` suppressed only `Condition="'$(TargetFramework)' == 'net8.0'"` once that leg is past EOL, citing [#19](https://github.com/Skymly/FastReflection/issues/19); every further suppression carries an inline justification.
- **SDK pin** — `global.json` pins the `10.0.x` SDK band with `rollForward: latestFeature`.
- **CI topology** — Nuke `GitHubActions` attribute change with regenerated `ci.yml` (never hand-edited): windows-latest builds all TFMs and tests `net472;net6.0;net8.0;net10.0`; ubuntu-latest builds all TFMs, tests `net6.0;net8.0;net10.0`, and runs the linux-x64 AOT smoke; the `Test` target selects legs by OS. `publish.yml` untouched.
- **AOT smoke** — `tests/FastReflection.AotSmoke` console app, `PublishAot` for `linux-x64` on the ubuntu leg, exit code 0 on pass; fixed scenarios per [#9](https://github.com/Skymly/FastReflection/issues/9) growing with the surface.
- **Coverage gate** — `coverlet.collector` cobertura on the newest modern leg; the job fails below **90% line coverage on any shipped assembly**; report uploaded as a CI artifact.
- **Benchmark gate** — BCL-baseline rows kept, reference-library comparison rows added as features land (never gated); legs `net472;net8.0;net10.0`; a dedicated Nuke `Benchmark` target plus windows-latest CI job; a FastReflection benchmark fails when its mean is **>25% slower** than the committed baseline file; baseline refresh is a deliberate maintainer run plus PR.
- **Gate audit** — one-time proof, recorded in the implementing PR, that each gate fails when violated and passes on compliance.
