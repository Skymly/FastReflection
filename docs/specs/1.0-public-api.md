# FastReflection 1.0 public API

The authoritative spec for every public member 1.0 ships, across all three packages. Decided by the wayfinder council on map [#1](https://github.com/Skymly/FastReflection/issues/1); specified on [#20](https://github.com/Skymly/FastReflection/issues/20). This document discharges every "lands at the spec hop" deferral in tickets #6–#19: the names, signatures and spellings recorded here are the decisions those tickets reserved — implementation does not re-open them.

Scope verdicts live on the deciding tickets (traceability at the bottom); the scope matrix and acceptance checklist live in `docs/plans/1.0.md`. `CONTEXT.md` is unchanged by this spec — bound calls are not accesses and admit no glossary noun (the non-goal rewrite rides the scope-ADR hop).

## Shipped surface that stays

The 0.1 surface ships unchanged except where a later section says otherwise:

- `ReflectionExtensions` (static): `Unreflect<TDelegate>(this MethodInfo)`; `CreateGetter`/`CreateSetter` in open (`object?`) and `<TDeclaring, TValue>` typed forms over `PropertyInfo` and `FieldInfo`; `CreateInvoker(this MethodInfo)` → `FastInvoker`; `CreateInvoker<TDelegate>(this MethodInfo)`; `CreateInvoker(this ConstructorInfo)` → `FastConstructorInvoker`; `CreateFactory(this ConstructorInfo)`; `CreateFactory(this Type, bool nonPublic = false)`; net8.0+ `CreateSpanInvoker(this MethodInfo)` → `FastSpanInvoker` and `CreateSpanInvoker(this ConstructorInfo)` → `FastSpanConstructorInvoker`. Gains `CreateConverter` (below).
- Delegate types `FastInvoker`, `FastConstructorInvoker`, and net8.0+ `FastSpanInvoker`, `FastSpanConstructorInvoker`.
- `Ref<T>` — the mutable holder for by-ref parameters.
- `TypeAccessor` (abstract): `Create(Type, bool allowNonPublicAccessors = false)`, `Type`, the `[object? target, string name]` indexer, ordinal `GetValue`/`SetValue`, `TryGetOrdinal`, `GetMembers()`, `CreateNewSupported`, `CreateNew()`. Gains the bound-call verbs (below) and the freeze-fix constructor.
- `ObjectAccessor` (abstract): `Create(object, bool allowNonPublicAccessors = false)`, `Target`, the `[string name]` indexer. Gains the same verbs without `target`, the freeze-fix constructor, and the `Equals` fix.
- `Member` (sealed): `Name`, `Type`, `MemberInfo`, `Ordinal`, `CanRead`, `CanWrite`, `IsProperty`, `IsField`, `IsDefined(Type, bool)`. Gains `GetAttribute`.

## Core bound-call surface (#7, #13)

New members on the two accessors; no `object` extensions, no new glossary nouns.

- `TypeAccessor` gains: `object? Invoke(object? target, string name, params object?[]? args)`; `object? Invoke(object? target, string name, object?[]? args, IReadOnlyDictionary<string, object?>? namedArgs, Type[]? typeArguments)`; and `TryInvoke` mirrors returning `bool` with an `out object?` result. `ObjectAccessor` gains the same verbs without the `target` parameter.
- Get/set by name over the *bindable* domain — instance and static properties and fields, plus indexer get/set via index arguments — as overloads beside the shipped ordinal forms: `object? GetValue(object? target, string name, params object?[]? index)`; `void SetValue(object? target, string name, object? value, params object?[]? index)`; `TryGetValue`/`TrySetValue` mirrors. These are value members, not `Get*`: a name miss is `MissingMemberException`. The shipped `[target, name]` indexer and `Member` domain stay instance-only; a bound call on a static member ignores `target` per the access target rule.
- `object CreateNew(object?[]? args, IReadOnlyDictionary<string, object?>? namedArgs = null)` overload for constructor binding, plus `TryCreateNew`; `CreateNewSupported` keeps its parameterless meaning. A value type's default value remains reachable through `CreateNew()` and is not an access.
- `IReadOnlyList<string> GetMemberNames()` on both accessors (object accessor forwards): the distinct, case-sensitive names bindable at this accessor's visibility — methods, properties, fields, and the indexer item name; accessor `get_`/`set_` spellings and constructors are not listed; overloads collapse to one entry.
- `Func<object?, object?> CreateConverter(Type sourceType, Type targetType)` on the extensions class — a `Create`-shaped bounded converter (not a name lookup, not a `Type` extension): spec numeric conversions, reference casts/unboxing, `Nullable<T>` lift/unlift, enum↔underlying; user-defined `op_Implicit`/`op_Explicit` never consulted; failure is `InvalidCastException`.

### Resolver contract (from #7 Q2)

Applicable conversions are identity, reference, unboxing, `Nullable<T>`, enum↔underlying, and spec §10.2.3 primitive widening *including* `→decimal` and *excluding* `byte→char`; `null` applies only to nullable targets; named-argument reordering, `params` normal/expanded, optional fill (a candidate needing no substitution beats one that fills), and explicit generic type arguments with constraint checks per spec §12.6.4; user-defined conversions, type inference, const narrowing, and extension-method search never apply; names are case-sensitive.

### Bound-call trigger order (from #7 Q4)

1. Null name → `ArgumentNullException`; absent name → `MissingMemberException`.
2. Candidates but none applicable — including unmatched named argument or arity — → `MissingMethodException`; best-match tie → `AmbiguousMatchException`.
3. Null `args` → `ArgumentNullException`.
4. Target rules (null instance target → `ArgumentNullException`; wrong runtime type → `InvalidCastException`; static ignores target).
5. Per-argument sanctioned-conversion failure → `InvalidCastException`.
6. Callee exception propagates unwrapped, no `ref`/`out` write-back.

`Try*` returns `false` on stages 1–2 and swallows nothing else.

### Bound-invoker cache

The bound-invoker cache lives on the accessor cache, keyed by (closed `Type`, visibility, member kind, name, normalized signature: runtime argument types + named-argument names/order + explicit type arguments); strong `Type` keys, no public flush, growth bounded only by call-site variety — documented in remarks.

A bound call resolves once, then runs as an adapted invoker through the same emit/reflection machinery — the parity gate and unwrapped-callee contract apply unchanged.

## Accessor deltas (#11)

- `Member` gains `Attribute? GetAttribute(Type attributeType, bool inherit = true)` and `T? GetAttribute<T>(bool inherit = true) where T : Attribute` — a `Get*`: null on a miss.
- New public `OrdinalAttribute` (`AttributeUsage` on property|field, `AllowMultiple = false`, one `int` value): members carrying it sort by value ascending; unattributed members sort after attributed ones; ties keep enumeration order; `Member.Ordinal` remains the positional index in the resulting list — the attribute is an ordering input, never a visible index (migration-table item vs fast-member, where `Ordinal` *is* the attribute value).
- Everything else shipped stays: `TryGetOrdinal`, `GetMembers()`, `CreateNewSupported`, the ordinal `GetValue`/`SetValue`, the `[target, name]` indexer with `Require` miss semantics.

## 0.1 freeze fixes (#6)

- `TypeAccessor` and `ObjectAccessor` each get a constructor external code cannot call (internal on the abstract type); both stay abstract; `Create` remains the only obtain path.
- `ObjectAccessor.Equals` becomes symmetric: an accessor equals another accessor iff their targets are equal, and never equals the raw target; `GetHashCode` follows the target; `ToString` may still forward. The 0.1 test `ObjectAccessor_EqualsDelegatesToTarget` is rewritten to the new contract.

## Exception contract and parity fixes (#8)

The #8 contract lands verbatim as [ADR-0004](../adr/0004-one-exception-contract-for-emit-and-reflection-completion.md), beside ADR-0002: BCL exception types only; type and trigger condition contractual, message text/`ParamName`/localization not; the creation and call trigger orders contractual; `Get*`/`Try*`/`Require*` naming; `Unreflect` and exact-bind delegates outside this order.

Observable fixes both paths must make: null instance target → `ArgumentNullException`; null written to a non-nullable value type → `InvalidCastException` with no write; numeric widening/narrowing on member writes and arguments fails `InvalidCastException`; callee exceptions propagate unwrapped; null `args` → `ArgumentNullException`; wrong argument count → `ArgumentException` (extra args never ignored); an unwritable `Member` → `InvalidOperationException`; a null `in` slot is not written back; creating a ref-return write without a setter when dynamic code is unavailable → `NotSupportedException`.

Both `MissingMemberException` on unwritable Members (today) and reflection-path `TargetException`/`TargetParameterCountException`/`TargetInvocationException` wrapping are defects removed by this work.

## AOT/trim annotations (#9, extended for bound calls)

- `CreateInvoker<TDelegate>` is the only public member carrying `RequiresDynamicCode`, with remarks pointing exact-bind callers to `Unreflect`; every other public member stays unannotated.
- `DynamicallyAccessedMembers` union sets, extended beyond #9's list because bound calls widen member discovery to methods and all constructors: `TypeAccessor.Create.type` and `ObjectAccessor.Create.target` get `PublicProperties | NonPublicProperties | PublicFields | NonPublicFields | PublicMethods | NonPublicMethods | PublicConstructors | NonPublicConstructors | Interfaces`; `CreateFactory(Type).type` gets the parameterless-constructor pair; `CreateInvoker<TDelegate>`'s `TDelegate` gets `PublicMethods`. Methods taking a materialized `*Info` get nothing.
- Internals: `Emit*` members carry `RequiresDynamicCode`; public wrappers suppress IL2026/IL3050 via `UnconditionalSuppressMessage` justified by the `DynamicCodeSupported` guard plus documented reflection fallback; `Ref<T>.Value` is kept by `DynamicDependency`; downlevel TFMs gain name-matched polyfill attributes beside the existing ones.
- `Member.IsDefined`/`GetAttribute` `attributeType` parameters are audited at implementation: annotate only if the linker demands a minimal member set.
- The annotations land in this spec's implementation; the *gates* (`IsAotCompatible`, warnings-as-errors, the PublishAot smoke app and its RID matrix) are the quality-gate spec's, out of scope here.

## Satellites (#12, #15, #19)

### `Skymly.FastReflection.ObjectReader`

Assembly and root namespace `FastReflection.ObjectReader`; sealed `ObjectReader : DbDataReader` obtained only via `Create<T>(IEnumerable<T> source, params string[] members)` and `Create(Type elementType, IEnumerable source, params string[] members)` (no public ctor — wontfix). Columns are the supplied case-sensitive member names in supplied order, or all Members of the *public* type accessor in accessor order (honoring the ordinal attribute) when none are given; an unknown name fails at `Create` with the accessor's `MissingMemberException` — no silent `object` column. Column type is `Nullable`-unwrapped; `AllowDBNull` is reference-type-or-`Nullable<T>`; reads surface `DBNull.Value` for null. Full `DbDataReader` surface covering the `SqlBulkCopy`/`DataTable.Load` path: `FieldCount`, `GetName`, `GetOrdinal`, `GetValue`/`GetValues`, typed `Get*`, `IsDBNull`, `GetFieldType`, `GetDataTypeName`, `Read`, `IsClosed`, `HasRows`, `Close`, `GetSchemaTable` (`ColumnOrdinal`/`ColumnName`/`DataType`/`ColumnSize`/`AllowDBNull`), `GetEnumerator` via `DbEnumerator`, indexers. Zero third-party dependencies; `DbColumn`/`GetColumnSchema` metadata is post-1.0; reverse direction, bulk helpers, non-public columns, member probes and `IDataReader`→`DataTable` helpers are wontfix.

### `Skymly.FastReflection.XmlDocs`

Assembly and root namespace `FastReflection.XmlDocs`; extension methods on `MemberInfo`/`Type`/`ParameterInfo`/`Assembly` (satellite receivers are not bound by the core's receiver budget): `GetXmlDocsSummary`, `GetXmlDocsRemarks`, `GetXmlDocsElement` (`XElement?`), `GetXmlDocsTag(string)`, parameter docs via `GetXmlDocs(this ParameterInfo, …)`, and an `XmlDocsOptions` carrying a doc-file path override and external-docs resolution. XML files resolve beside the assembly location; results are cached internally per assembly with the unload-safe `ConditionalWeakTable` treatment from the cache research (#4); no public flush. `GetXmlDocsPath`, `ToXmlDocsContent`, `GetXmlDocsRecordPropertySummary`, `ClearCache`, and the Cecil variant are wontfix.

## Package topology, signing, docs (#10, #19)

- Three projects produce `Skymly.FastReflection`, `Skymly.FastReflection.ObjectReader`, `Skymly.FastReflection.XmlDocs`; satellites `ProjectReference` the core through public API only, no `InternalsVisibleTo` from the core (a satellite may friend-grant its own test assembly); lockstep `$(Version)` and all shared packaging/signing props hoist to `Directory.Build.props`.
- TFM set `net462;netstandard2.0;net8.0;net10.0` on all three packages; test matrix `net472;net6.0;net8.0;net10.0` (net472 consumes the net462 asset, net6.0 the netstandard2.0 asset); `NET8_0_OR_GREATER` code compiles on net10.0 unchanged; after net8.0 EOL a scoped `NoWarn` on NETSDK1138 with an explanatory comment — net8.0 removal is a 2.0 question.
- Strong naming per [ADR-0003](../adr/0003-one-committed-key-signs-every-target.md): one committed key pair signs every shipped target and the test assemblies; `AssemblyVersion` is major-only; `FileVersion` carries the full package version; the core's `InternalsVisibleTo` to tests names the public key; satellites share the key with no inbound IVT; no signed twin.
- README: per-package READMEs (satellite NuGet pages describe the satellite); the core README gains a section per shipped item, an AOT/trim section, and the migration tables from fast-member, Dynamitey, Namotion.Reflection and DotNext.Reflection recording the named deviations (positional `Member.Ordinal`, no-user-conversions `InvokeConvert`, no `TargetInvocationException` wrapping, fail-fast columns, no source shim — with the documented compositions for wontfix items such as `Dynamic.Invoke` → `DynamicInvoke`/`CreateInvoker`).

## Testing approach

- **What makes a good test**: only external behavior — call the public surface, assert the returned value, the written member, or the exception *type* (never message text). No IL inspection, no internal-state assertions; `InternalsVisibleTo` exists only for the fallback hook, not for probing resolver or cache internals.
- **Seams** (confirmed — the minimum set): the public API surface itself is the highest seam and carries every test; the existing `EmitHelper.ForceReflectionFallback` hook carries the emit/reflection parity leg — every contract behavior is asserted identically on both paths; `ObjectReader` is verified through real `DbDataReader` consumers (`DataTable.Load`, `GetValues`, typed getters) rather than mock readers; `XmlDocs` reads the test assembly's own generated documentation file (and a fixture file for options) so the resolution seam stays the public surface. No new seams.
- **Modules tested**: every new/changed public member on both accessors; the resolver as a decision table (widening set incl. `→decimal` / excl. `byte→char`, null-to-nullable only, named/optional/`params`, explicit type args + constraint checks, no user conversions, case-sensitive miss); bound-call trigger order with multi-condition calls asserting the first-holding exception; `Try*` miss→false without swallowing later stages; `Ref<T>` write-back parity incl. null `in` slot; the parity fixes themselves (each #8 fix gets a both-paths test); `GetAttribute`/`OrdinalAttribute` ordering incl. ties and mixed attributed/unattributed; freeze fixes (no external subclassing — compile-verified by convention, `Equals` symmetry pairs); `ObjectReader` end-to-end incl. fail-fast `Create`, column order/type/nullability, `GetSchemaTable`, enumerator; `XmlDocs` summary/remarks/tag/element/param reads plus options.
- **Prior art**: `AccessorEmitTests` for per-shape contract tests, `InvokerTests` for `ref`/`out` write-back, `TypeAccessorTests` for member-domain and exception assertions, `FallbackTests` for the parity-leg pattern (ctor sets the flag, `Dispose` resets), `Fixtures` for sample types; xUnit, `[Fact]`/`[Theory]`, assembly-wide parallelization already disabled because of the shared flag.
- **Multi-leg coverage**: every behavior test runs on `net472;net6.0;net8.0;net10.0`; net8.0-only surface (span invokers) stays `#if`-gated as today.

## Out of scope

- Decided exclusions stand: member paths/chains and events by name (post-1.0); operator verbs, `CoerceConvert`, `InvokeContext` context-type parameter, case-insensitive names, IDMOP/`DynamicObject`/COM targets, user-defined conversions, generic type inference, const narrowing, extension-method search, any DLR/`Microsoft.CSharp` dependency (wontfix); live-reference returns; `FastMember` source shim; `MemberSet`; `GetMembersSupported`; `Dynamic.Invoke`/`InvokeAction`; the whole `Type<T>`/member-object/argument-pack surface; custom exception types.
- `ObjectReader` wontfix set (public ctor, reverse direction, bulk helpers, non-public columns, probes) and `DbColumn` metadata; the `XmlDocs` wontfix set; the post-1.0 doc-tooling domain (contextual carrier, attribute split, NRT reading); post-1.0 type utilities; the source-generator companion.
- Quality-gate engineering — `IsAotCompatible`, IL2xxx/IL3xxx warnings-as-errors, the PublishAot smoke app and RID matrix, PublicAPI baselines, package validation, coverage gate, benchmark method, the ubuntu CI leg — is the separate quality-gate spec (the annotations themselves land here).
- The scope ADR, `docs/plans/1.0.md` matrix, `CONTEXT.md`/README non-goal rewrite, and landing ADR-0002 onto `main` — the separate scope-ADR hop.
- Release mechanics: no version bump, tag, GitHub Release or NuGet push; `<Version>` stays `0.1.0`.
- A cache-lifetime ADR — `ConditionalWeakTable` was verified to meet the unload gate on every target (#4); strong keys stand per ADR-0002.

## Implementation notes

- Suggested PR slicing (one PR per unit, quality gates may land ahead per the map): (1) topology + signing + TFM legs; (2) exception-contract parity fixes + ADR; (3) freeze fixes; (4) accessor deltas (`GetAttribute`, `OrdinalAttribute`); (5) bound-call resolver + verbs + cache; (6) `ObjectReader` satellite; (7) `XmlDocs` satellite; (8) AOT annotations + polyfills; (9) READMEs + migration tables. Parity fixes should precede bound calls so the shared machinery is contractual first.
- `MissingMemberException` currently thrown for unwritable Members is a contract defect — the migration table and changelog should flag the change to `InvalidOperationException`.
- Bound-invoker cache growth is accepted as call-site-bounded and documented; a future cap is a design question, not a defect.
- Traceability: binding model #7; verbs and statics/indexers/convert/enumeration #13; accessor deltas #11; exception contract #8; annotations #9; concept model + freeze fixes #6; satellites #12/#15; topology + naming #19; strong naming #10; cache research #4; usage census #2.
